# 🚁 Mini Drone

> Compact quadcopter drone capable of lifting a 20 g payload.

## 📖 Overview

A compact drone built from the ground up that can **lift a payload of 20 grams**.

## ❓ Problem

Building a small drone is a hands-on way to learn flight control, motor control, power management and weight balancing in a tight form factor.

## ✨ Key Features

- Lightweight compact frame
- Lifts a 20 g payload
- Balanced load distribution for stable flight
- Hardware diagnostics and tuning

## ⚙️ How It Works

1. Flight controller reads orientation from on-board sensors
2. Control loop adjusts motor speeds to keep the drone stable
3. Motor drivers power the propellers
4. Payload is balanced around the centre of gravity

## 🛠️ Tech & Skills

`Flight Control` `Motor Drivers` `Load Balancing` `Hardware Diagnostics`
